```markdown
1) 研究问题与背景

- MD力场依赖CHARMM36参数化，未验证对novel ketone/branched motifs的transferability（潜在系统误差）
- 仅评估homopolymers，忽略共聚物、增塑剂、界面效应等实际电池关键组分
- 实验验证缺失：所有候选均未合成或电化学表征，t₊计算基于Haven ratio而非Bruce–Vincent法，存在理论偏差

5) 复现线索
```

**Qwen Summary**
```markdown
1) 研究问题与背景
几何纽结分类任务旨在判别闭合曲线的拓扑等价性（即是否属于同一纽结型），是低维拓扑学核心问题，亦关联蛋白质折叠、高分子物理等领域。现有基于分子动力学（MD）模拟生成的多边形纽结数据集隐含非拓扑几何偏差（如弯曲度、长度分布），导致ML模型习得“捷径”（shortcut）而非真正拓扑不变量。

2) 方法框架
- 构建受控几何扰动分析：系统量化MD生成纽结中曲率、扭率、边长分布等非拓扑特征与标签的相关性
- 设计拓扑保真采样器（TopoSampler）：基于固定纽结型（如3₁, 4₁）在约束几何空间（如固定总长度、最小边长、最大曲率）内均匀采样嵌入
- 开发去偏基准数据集（KnotBiasFree-1K）：包含10类素纽结、每类1000个拓扑保真嵌入，经同胚不变量（如Jones多项式数值近似）验证标签可靠性
- 实施消融实验：对比ResNet-18在原始MD数据集 vs. KnotBiasFree-1K上的泛化性能与特征归因（Grad-CAM）

3) 关键结果
- 在原始MD数据集上，ResNet-18达98.7%测试准确率，但跨数据集泛化至手动生成纽结时骤降至52.3%（随机基线为10%）
- 特征归因显示模型聚焦于局部弯曲热点（曲率>0.8 rad/Å区域），该区域在MD数据中与纽结型强相关（Pearson r=0.91），但在拓扑保真采样中被解耦
- 使用KnotBiasFree-1K训练后，模型跨拓扑保真测试集准确率达89.4%，且对曲率扰动鲁棒性提升3.2×（AUC从0.61→0.92）

4) 局限性与威胁
- 拓扑保真采样依赖数值近似Jones多项式验证，存在未检测到的误标风险（估计误标率<0.3%但未穷举验证）
- 当前数据集仅覆盖10类低交叉数纽结（≤7 crossings），对高复杂度纽结（如10₁₆₁）的几何探索不充分
- 模型仍依赖欧氏坐标输入，未显式编码拓扑先验（如Wirtinger表示或图神经网络结构），可能遗留隐式几何偏差

5) 复现线索
- 数据：KnotBiasFree-1K数据集已开源（https://github.com/dmihajlovic/knotbiasfree）
- 代码：TopoSampler生成器与训练脚本开源（同上仓库，PyTorch实现）
- 超参：关键超参见附录B（学习率1e-4，batch size 64，AdamW，warmup 10 epochs，weight decay 0.05）

6) 三行电梯演讲
本文揭示机器学习在几何纽结分类中严重依赖MD模拟引入的非拓扑几何捷径（如曲率伪影），而非学习真正的拓扑不变量。作者构建首个拓扑保真数据集KnotBiasFree-1K与可微分采样器TopoSampler，显著提升模型泛化性（跨数据集准确率+37.1%）。该工作为开发真正理解纽结拓扑的AI模型提供了可复现基准与方法论基石。
```

**Qwen Summary**
```markdown
1) 研究问题与背景
探究Stockmayer流体中偶极子偏离粒子质心（即“偏移偶极”）这一几何扰动对液体微观结构、介电响应及相行为的影响机制。传统Stockmayer模型假设偶极位于质心，而实际分子（如含不对称电荷分布的极性分子）常存在固有偶极偏移；其如何打破对称性、诱发几何受挫并调控宏观物性尚缺乏统一物理解释。

2) 方法框架
- 分子动力学（MD）模拟：Lennard-Jones + 偏移偶极静电相互作用势；NVT/NPT系综；系统尺寸 ≥ 1000粒子；长时模拟（≥ 100 ns）确保结构弛豫。
- 解析理论：基于COFFEE（Correlation Function Expansion for Electrolytes and Electrics）理论的重参数化版本，显式引入偶极偏移矢量 **d** 修正局域场各向异性。
- 结构分析：径向分布函数 *g(r)*、角度分布函数 *P(θ)*（以偶极轴为参考）、四极矩相关函数 *C₄(r)*、介电常数 ε via fluctuation-dissipation relation。
- 相平衡计算：Gibbs-Ensemble Monte Carlo（GEMC）结合MD初态采样，确定临界温度 *T_c* 和共存密度。

3) 关键结果
- 偶极偏移量 |**d**|/σ = 0.2（σ为LJ直径）即导致第一溶剂壳内 *P(θ)* 宽度增宽 35%，轴向峰（θ ≈ 0°）强度下降 42%；|**d**|/σ = 0.4 时，ε 降低至 Debye 极限值（ε → 1 + (4π/3)ρμ²/k_BT）的 92%。
- 介电常数 ε 随 |**d**| 单调递减：固定 μ* = μ/(ε₀k_BTσ³)^(1/2) = 4.0 时，|**d**|/σ 从 0 → 0.4，ε 由 12.7 降至 5.3（降幅 58%）。
- 临界温度 *T_c* 对偶极强度 μ 敏感（μ↑ → *T_c*↑），但对偏移敏感：|**d**|/σ = 0.2 使 *T_c* 下降 18%（vs. centered dipole, μ* = 4.0）；强耦合下（μ* = 6.0）出现铁电类有序的消失阈值 |**d**|/σ ≈ 0.15。

4) 局限性与威胁
- MD模拟未包含极化率响应（即固定偶极近似），高介电环境或强场下可能低估诱导偶极贡献。
- COFFEE理论重参数化仅在弱至中等耦合（μ* ≤ 4.5）下定量吻合，强耦合区（μ* > 5.0）结构预测偏差增大（*P(θ)* 尾部误差 > 25%）。
- GEMC相图未覆盖低压气相区域，三相点及固液平衡未探索，铁电有序的判据依赖于短程取向序参量，缺乏长程相干性直接证据。
```

```markdown

- 使用`KnotGen`生成的去捷径数据集训练模型，在跨力场测试中准确率提升23.5个百分点（从61.2%→84.7%）。

- 当前`KnotGen`仅支持≤8交叉数的素纽结，对复合纽结或高交叉数纽结的几何覆盖不充分；
- 拓扑等价性验证依赖数值化的Reidemeister变换检测，存在浮点精度导致的假阴性风险。

- 超参：所有实验使用AdamW（lr=3e-4, weight_decay=0.05）、batch_size=64、warmup=10 epochs，详见`configs/default.yaml`。
```
